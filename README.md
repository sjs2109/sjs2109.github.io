# sjs2109.github.io

Moonwalk 테마로 다시 구성한 개인 글 사이트입니다.

## 운영 원칙

- `llm_wiki`에서 글감을 찾고 공개용 초안을 작성합니다.
- 개인정보와 원문 재현 위험을 검사한 뒤에도 초안 상태로 보관합니다.
- `llm_wiki`의 승인 페이지에 명시적인 승인이 기록된 글만 게시 후보가 됩니다.
- 공개 사이트에는 승인된 글만 반영합니다.

## 로컬 실행

```sh
bundle install
bundle exec jekyll serve
```

사이트는 [Moonwalk](https://github.com/abhinavs/moonwalk)을 기반으로 합니다. 테마 코드는 원본 MIT 라이선스를 따릅니다.
